# Halt report

This is the halt report the Equivalence failure constraint (AAP 0.11.2) requires. A COBOL path that cannot be interpreted to exactly one result halts that case. The constraint names no exception, so a halted case is blocked: no parity assertion is written for it, every binding that covers it is reported `BLOCKED` and never passed, and Done (g8) cannot be reached while any row here stays `BLOCKED` (AAP 0.8.5, 0.9.5). Under R7 — Anomaly handling, a halt is the derive-lane outcome for an anomaly that has no single result, and each row names the escalation in `ESCALATIONS.md` that hands its case here, where one exists. Nothing in this file describes a halted case as equivalent or passed.

Where the surrounding flow cannot run without a halted path (every CP00 reply has H6's length), the code implements every audited rule around the path and marks the path itself `HALTED(Hn)` in a code comment and in the audit row. That code is not a parity result, and nothing asserts it as one. An audit row covered by a halt carries `HALTED(Hn)` in its Expected result, and the tests that bind it report it blocked. Halt IDs are cited by audit rows, rule modules and tests, so an ID is never renumbered or reused.

Status values:

- `BLOCKED`: the initial status of every row. The bindings the row lists cannot pass.
- `RESOLVED`: set only when the reviewer confirms a source-backed resolution against its cited source. The source is repository source that fixes one result, or, for an external API (CEEDAYS, Language Environment storage initialisation, Db2, CICS, MQ or IMS message texts and codes), vendor documentation of the deployed behaviour. The Resolution cell cites the source and carries the reviewer's name and date. The case then becomes ordinary audit rows with tagged tests.
- `DESCOPED`: set only on an explicit user scope change. The Resolution cell quotes the user's instruction.

A reviewer's acknowledgement of a halt's analysis is recorded in the halt acknowledgement table of `modern/audit/README.md`. It does not change the row's status: an acknowledged halt stays `BLOCKED`.
